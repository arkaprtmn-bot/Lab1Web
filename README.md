Jawaban Pertanyaan HTML Dasar

1. Apa fungsi deklarasi <!DOCTYPE html> pada dokumen HTML?
<!DOCTYPE html> berfungsi untuk memberi tahu browser bahwa dokumen yang dibuat menggunakan standar HTML5. Deklarasi ini ditulis di bagian paling awal dokumen HTML. 

2. Apa perbedaan antara tag, elemen, dan atribut pada HTML?
Tag adalah penanda yang digunakan untuk membuat atau menandai suatu bagian dalam HTML, contohnya <p> dan <h1>. Elemen merupakan keseluruhan bagian yang terdiri dari tag pembuka, isi, dan tag penutup. Sedangkan atribut memberikan informasi tambahan pada sebuah elemen, biasanya ditulis di dalam tag pembuka.  

3. Apa perbedaan <p> dengan <br>? Jelaskan penggunaannya.
<p> digunakan untuk membuat sebuah paragraf, sedangkan <br> digunakan untuk membuat pindah baris. Jadi, <p> lebih digunakan untuk mengelompokkan teks menjadi paragraf, sementara <br> hanya untuk membuat teks berpindah ke baris berikutnya. 

4. Apa fungsi atribut href pada tag <a>?
Atribut href digunakan untuk menentukan alamat atau tujuan dari sebuah hyperlink. Tujuannya bisa berupa halaman lain, website eksternal, atau bagian tertentu dari halaman yang sama. 

5. Apa perbedaan hyperlink ke halaman internal dengan hyperlink ke website eksternal?
Hyperlink internal mengarah ke halaman atau bagian yang masih berada di dalam website atau project yang sama, contohnya halaman2.html. Sedangkan hyperlink eksternal mengarah ke website lain, contohnya https://www.google.com. 

6. Apa fungsi atribut src dan alt pada tag <img>?
Atribut src digunakan untuk menentukan lokasi atau path gambar yang akan ditampilkan. Sedangkan alt digunakan untuk memberikan deskripsi atau keterangan tentang gambar. 

7. Apa perbedaan penggunaan <ul> dan <ol>?
<ul> digunakan untuk membuat daftar yang tidak berurutan atau tanpa nomor. Sedangkan <ol> digunakan untuk membuat daftar yang berurutan atau menggunakan nomor. 

8. Apa yang terjadi jika path gambar pada atribut src salah?
Jika path pada atribut src salah, gambar tidak dapat ditemukan sehingga gambar tidak akan tampil dengan benar pada halaman web.

9. Mengapa struktur heading <h1> sampai <h6> perlu digunakan secara terstruktur?
Karena heading digunakan untuk membedakan judul utama dan subjudul pada halaman web. <h1> merupakan heading utama, kemudian <h2>, <h3>, dan seterusnya digunakan untuk bagian yang lebih spesifik. Dengan struktur yang teratur, isi halaman menjadi lebih mudah dipahami. 

10. Apa fungsi komentar <!-- ... --> dalam kode HTML?
Komentar digunakan untuk memberikan catatan atau informasi tambahan di dalam kode HTML. Komentar tidak ditampilkan pada halaman web oleh browser. Komentar juga bisa digunakan untuk menonaktifkan kode sementara.
